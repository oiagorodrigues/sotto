# Security checklist

Each item names how it is checked: `auto` (part of `just check` or a test), or `manual` (run by hand at the end of each slice and recorded below).

| # | Requirement | Check |
|---|---|---|
| 1 | Tauri `>= 2.11.1`; `cargo deny` bans older versions and crates with open advisories | auto |
| 2 | Capabilities per window, deny by default; no `tauri-plugin-shell`; no remote domain IPC access | auto (config test) |
| 3 | CSP: `default-src 'self'`; no remote scripts, styles or fonts; no `unsafe-eval` | auto (config test) |
| 4 | No runtime downloads from CDNs; model and asset downloads pinned by SHA-256 | auto (grep rule) + manual |
| 5 | Every webview intent is a typed command with `deny_unknown_fields`, validated before it changes state | auto (tests) |
| 6 | Login callback requires a matching `state` from this process and a PKCE verifier | auto (tests) |
| 7 | Secrets only in the Keychain: provider keys, refresh token, database key. A provider key is typed once in the settings webview, sent in a single `set_api_key` intent (validated in the core, `ApiKey` has a redacting `Debug`), written to the Keychain by the core and never echoed back: snapshots carry only the first 6 and last 4 characters. The database key is generated by the shell with the OS CSPRNG and read only at start. | auto (grep rule) + manual |
| 8 | Local database encrypted (SQLCipher) with a Keychain-held key | auto (test opens the file without the key and fails) |
| 9 | Sidecar launched by absolute path; `PATH` never modified | auto (grep rule) |
| 10 | Bounded queues with overflow counters; no silent drops | auto (tests) |
| 11 | Echo cancellation through voice processing; mic never zeroed | manual |
| 12 | Logs never contain transcript text, prompts, answers, keys or tokens | auto (log redaction tests) + manual |
| 13 | Entitlements: audio input only; no camera; hardened runtime | auto (entitlements file check) |
| 14 | Login item off by default | manual |
| 15 | Overlay invisible to: macOS screenshot, QuickTime recording, Zoom share, Google Meet share in Chrome | manual |
| 16 | Cloud transcription only after opt-in; active engine shown per session | auto (core tests for the opt-in rules) + manual |
| 17 | Backend: no meeting-content endpoints; argon2id; hashed tokens; rate limits; non-root container; `cargo audit` | auto + manual |
| 18 | Origin and other request headers are not rewritten globally | auto (grep rule) |
| 19 | The embedding model is used only when its installed digest equals the one in `config/embedding.toml`; a mismatch is refused with a notice | auto (tests) |
| 20 | The webview never sends or receives file paths or file contents: the file panel opens from Rust, the shell hands paths to the core, and the core checks type and size | auto (intent tests, config test) + manual |
